# 기업별 포트폴리오 운영 원칙

2026-09-30 사용자 결정: 회사마다 원고가 늘어나 혼동하지 않도록, 하나의 범용 본문을 공유한다.

## 바꿀 수 있는 것

- 회사별 URL slug, 상단 기업명·지원 직군 표기(eyebrow).
- 테마 색상, 선·마커·타이포그래피·여백 등 시각적 표현. 다른 회사 페이지에 영향을 주는 변경은 피하고 테마 또는 캠페인 범위에 한정한다.
- 기본 인상은 라이트 모드, 격식 있는 미니멀 편집형 디자인을 유지한다.

## 공통으로 유지할 것

- 소개문, 프로젝트 설명·수치·한계·링크, 학습 내용, 경력, 기술, 연락처.
- 프로젝트·학습 항목의 선택과 읽는 순서. 회사별로 항목을 숨기거나 다른 본문을 생성하지 않는다.
- `profile`, `projects`, `studies`, `learnings`, `experience`, `skills`를 단일 공통 데이터로 사용한다.
- 회사 추가 요청은 공통 원고 수정 요청이 아니다. 사실 정정이 승인되면 공통 데이터를 수정하여 모든 페이지에 동일하게 반영한다.

## 새 회사 페이지 절차

1. 공식 회사 페이지에서 시각적 참고를 확인하고 출처를 기록한다. 로고를 그대로 삽입할 필요는 없다.
2. `src/data/themes.ts`에 필요 시 팔레트를 추가한다. 작은 글자는 대비를 확보한 `accentInk`를 쓴다.
3. `src/data/portfolio.ts`의 `campaigns`에 `{ slug, theme, label }`을 추가한다. 현재 `indexable`은 일반용만 true다.
4. `scripts/check-final.cjs`의 검증 대상과 `scripts/capture-site.cjs`의 캡처 대상에 새 slug를 추가한다.
5. 빌드 후 1440px·375px에서 본문 전체(접힌 상세 포함)의 동일성, 넘침·이미지·색상·링크·상세 펼치기·검색 설정을 확인한다.
6. 회사 페이지 작업은 기존 콘텐츠 수정과 분리하여 커밋한다. 배포 요청이 있으면 main 반영 후 공개 URL을 확인한다.

루트 `/`와 `/hanwha/`는 기존 한화금융 제출 주소로 유지한다. `/hanwha-ocean/`은 한화오션용이다. 기업별 페이지의 `noindex`는 검색 제외 요청이며 접근제어가 아니다.

## 에이전트에게 요청하는 예

“AGENTS.md와 policy/company-pages.md를 읽고, ○○회사 제출용 URL을 준비해줘. 공통 내용은 유지하고 회사에 맞는 디자인·색상만 적용해줘.”

미리보기만 필요한지, main 배포까지 필요한지는 작업 요청에서 구분한다.

## CJ올리브네트웍스 테마 (2026-09-30)

- URL: `/cj-olivenetworks/`, 상단 표기: `CJ OLIVENETWORKS · AI / DATA`.
- 공식 [회사 소개](https://www.cjolivenetworks.co.kr/company/overview)의 [로고 SVG](https://www.cjolivenetworks.co.kr/images/common/logo.svg)에서 파랑 `#006ECD`, 빨강 `#EF141D`, 주황 `#FF9700`을 확인했다. 공식 [웹사이트 CSS](https://www.cjolivenetworks.co.kr/css/common.css)도 `#006ECD`를 사용한다. 이는 공식 웹 자산에서 확인한 값이며 별도의 전체 CI 매뉴얼 준수 인증을 뜻하지 않는다.
- 파랑을 주 강조색으로, 세 가지 색은 96×5px 구분선 마커에만 사용한다. 본문 색과 편집 그리드는 유지한다.
- 작은 글자용 `#0057A3`와 옅은 배경 `#E8F2FC`는 이 포트폴리오의 가독성을 위해 선택한 파생색이다. 회사 로고 자체는 삽입하지 않는다.
