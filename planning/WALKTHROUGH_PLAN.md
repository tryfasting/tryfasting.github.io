# 포트폴리오 실행 계획

현재: **Swissfolio 라이트 틀 구현 완료 → 로컬 겉모습 검수 대기**

1. [x] 최소 구성과 호스팅 방향 정리.
2. [x] 무료 템플릿 조사 및 미리보기 후보 제시. → [후보 보기](REFERENCE_GUIDE.md#선택-가능한-외부-템플릿)
3. [x] 사용자 디자인 선택: Swissfolio + 제공 프롬프트, 라이트 모드·작은 인덱스 적용.
4. [x] 선택한 디자인으로 샘플 내용만 있는 로컬 틀 구현. Astro + Tailwind CSS v4.
5. [ ] 로컬 미리보기 제공 → 사용자 겉모습 검수 → 수정 → 틀 확정.
6. [ ] 이후 별도 진행: 담을 내용 선정.
7. [ ] 내용의 위치·순서·배치 결정 후 실제 원고·이미지 입력.
8. [ ] 사용자 최종 검수 후 기존 GitHub 사이트 확인 및 배포.

현재 진행 범위는 5번입니다. 색상·타이포그래피·여백의 최종 확정은 사용자 검수 후 진행합니다. 6~8번은 이후 별도 작업입니다.
