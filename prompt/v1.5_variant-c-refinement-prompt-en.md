# Instructions (for LLM coding agent) - Refine variant-c into three sub-variants

`variant-c-combined` is confirmed as the correct direction (scale + spacing combined). However, review of its screenshots surfaced three unresolved issues. ## Diagnosed issues to address (background, do not skip reading this)

1. **Profile photo competes with the h1 for visual weight.** The photo is roughly the same visual size as the name, so even though h1 was enlarged in variant-c, it doesn't read as clearly dominant. The original reference has no such competing element next to its headline.
2. **Orange accent has almost no visual impact.** It currently exists only as a thin 3px marker line, which reads as decorative and barely noticeable. It needs a slightly bolder presence without violating the ~3%-of-viewport usage cap or turning into a large solid block.
3. **The "Main Projects" card grid below the hero was untouched by any variant.** It still looks like the old v1.1 rhythm, so scrolling down loses whatever improvement was made in the hero. The four project cards' repeated thin underline is the only graphic rhythm there now, and it reads as monotonous.
